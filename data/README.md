> 문서 현행화 정본(2026-11-15): 사용자 보조 PDF 철회에 따라 검증된 **v0.17.3을 현재 운영으로 재활성화했다.** 승인 닉네임·테스터6명/영어 기본값은 유지하며 보조 고지 PDF는 공개 동선에서 제거했다. [철회·복귀 정본](../docs/releases/notice-withdrawal-20261115.json)을 따른다. v0.17.4의 수치·SHA·검증은 철회된 과거 이력이며 현재 배포가 아니다. Git 결과는 정본에서 확인하고 아래 날짜별 기록은 당시 이력으로 보존한다.

`raw/`, `calibration/`, `reference/`, `derived/`는 Git에서 제외한다. 작은 출처·해시·원격 ID 목록은 `manifests/`에서 추적한다. 원본을 수정하지 않고 파생 결과와 분리한다.

전체 자료 위치와 용도는 [docs/data_inventory.md](../docs/data_inventory.md)를 따른다. 내보내는 목록에는 이 컴퓨터의 절대 경로·개인정보·자격증명을 포함하지 않는다.

## 현재 사용 범위와 v0.17.0 기능 검증 스냅샷

현재 배포/검증은 보조 고지 PDF를 철회하고 v0.17.3을 재활성화한 [철회·복귀 정본](../docs/releases/notice-withdrawal-20261115.json)을 따른다. source 검증614개·runtime source1365/필수1270이며 기존114생성JSON/74비교 원핀은 동일하다. PDF 통합은 실행하지 않았다. v0.17.4의 source1366/필수1271은 보조 PDF가 있던 철회된 과거 검증이다. 아래 v0.17.0 자료 수·검사 결과도 당시 기능 검증 스냅샷으로 보존한다.

사용/확보/이전 자료의 전수 출처·파일 ID·바이트/SHA·권리·처리/한계는 [Data_Spec.md](../Data_Spec.md), 기능·검사 계약은 [FSD](../FSD.md)에 둔다. 이 README는 별도의 경쟁 명세나 과학 결과 정본이 아니다. 현재 제품은 태양계1000AU의 알려진 천체·공전/자전·3요건·실제 SPHEREx 관측·제9행성 가설과 근거 복원을 사용한다. 은하/지도·외계행성 도감·빅뱅/역사·블랙홀/범용 실험 자료는 이전 이력으로 보존하며 현재 코드/API/새 배포의 필수 자료로 다시 넣지 않는다.

- `manifests/datasets.json`·`observation_registry.json`: 관측 원본/보정 참조와 허용 대상·노출·쌍. 현재10대상·40제품·37무순서쌍을 양순서74비교로 제공한다. 방향/재처리/cutout 수를 독립 관측 수로 세지 않는다.
- `manifests/node_runtime.json`·`node-runtime/runtime_manifest.json`: v0.17.0 당시 Node가 재사용한 검증된 빌드 결과114JSON/63,027,446B와 source1365개(필수1270개). 당시 배포는 선택28개 present·67개 미배포를 구분했다. 현재 source/필수 수는 위 철회·복귀 정본을 따른다. Python은 개발 재검산/빌드 선택 경로이며 공개 Node 요청이 새 FITS 분석을 수행하는 것은 아니다.
- 태양계 천체력·장기 근사·확장 위성/외관·행성3요건·질량 가정은 해당 manifest별 source epoch/시간계·단위·누락/가정·유효범위를 유지한다. 1000AU는 연구 기준이며 물리적 벽이나 미발견 천체의 전수 복원이 아니다.
- `manifests/outer_tno.json`: JPL TNO snapshot8341개와 원소·식별·누락/외삽 한계. 실제 천체 궤도 유사도 TOP5는 사용자 가설의 a/e/i와 비교한 설명용 순위다. 그 순위를 발견·존재확률로 해석하지 않는다.
- `manifests/planet_nine_scope.json`: 문헌 합성 표본과 조건부 하늘 영역. 2018 원 RA/Dec·survey 조건/분모·입체각 단위를 보존하며 실제 TNO TOP5와 별도로 다룬다. 원표본의 하늘 확률밀도는 질량 밀도 kg/m³가 아니다.

DEV-027은 UI·저장 context·가이드/모바일 진입을 수정했고 새 원관측이나 물리 자료를 추가하지 않았다. 이전114생성 JSON과74비교 원핀의 동일성은 [v0.17.0 릴리스 정본](../docs/releases/v0.17.0.json)에 기록한다. 원본 이미지/FLAGS/DATE-AVG/TIMESYS·보정/출처 SHA와 기존 네 비교 정본·근거 봉투를 보존한다.

## 전달과 상태 복구의 구분

새 ZIP은 만들지 않고 필수 자료를 포함한 검증 디렉터리로 배포한다. Git에 없는 큰 채택 원본이 필요한 경우 Git clone만으로 준비 완료라고 하지 않는다. 공개 릴리스는 파일별 SHA를 대조하고, 개인키·팀 내부 문서·라이브 상태/로그·비공개 백업을 포함하지 않는다.

운영 상태는 자료 원본과 분리한 `/srv/planet-x/shared/node`다. OPS-021 새 호스트 `54.117.136.144`의 복구 범위는 로컬 불변 백업13파일(근거7·비교2·jobs4)과 실제 대조한 원바이트다. 별도 구판3근거는 부분집합이다. 삭제된 Sydney에서 이후 생긴 사본 없는 근거는 복구를 보장할 수 없다. 최신 stopped-writer24파일 백업의 로컬 다운로드/무결성 검증은 [OPS-021 기록](../docs/qa/ops021_migration_verification.json)을 따른다. 백업 내용은 Git/공개 자료가 아니다.
