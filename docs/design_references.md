# 디자인 참고 사이트 관찰 기록

사용자는 **Space Time을 특히 강하게 참고할 주 디자인/조작 기준**으로 지정했다. WWT/NASA Eyes는 보조 참고다. 이 파일에는 관찰과 출처를 남기고, 실제 개발 명세·수용 기준은 [FSD2절](../FSD.md)에 통합한다. 아래 초기 리뷰는 팀원 관찰이고, 별도 표기한 항목만 2026-11-14 실제 Chrome에서 확인했다. 모든 기능·수치·코드/라이선스를 검증한 것은 아니다.

## Space Time 실제 브라우저 확인 · 2026-11-14

- 기본 지구3D 화면, 주변 천체 선택·줌/홈·검색, 하단 모형시간/재생·날짜/범위 UI를 확인했다. 카메라 전체 자유도·모든 시간 구간의 정확도/성능을 검사한 것은 아니다.
- Explore를 열어 활동/목적별 진입과 안내/탐색 목록을 읽었다. 검색 팔레트에서 Pluto 검색→명왕성 선택→자동 카메라 이동/도착 및 천체 정보 패널을 관찰했다. 검색 이동의 한 사례이며 모든3D 클릭/목록 진입을 검사한 것은 아니다.
- 명왕성 정보에서 출처 모형 배지·학습/증거/궤도 탭을 확인했다. 별의 Evidence 탭에서 값의 기원·방법·한계를 표시하는 내용을 직접 읽었다. 실제 값/천체력·통계의 독립 검산은 하지 않았다.
- Observe 메뉴와 외계행성/NASA Archive 관련 검색 항목도 보였다. 이 항목의 기능 전체·SPHEREx 지원 여부는 확인하지 않았다. 상대 사이트에 관측/외계행성/출처 기능이 없다고 주장하지 않는다.
- 페이지는 분석 대상이다. 소스 코드·텍스처·음악·UI 자산을 가져오거나 사이트 계정/권한·공유·외부 자료를 변경하지 않았다. 자체 시각 품질/조작 설계의 참고와 자산 사용권은 별도다.

사용자는 탐구 대상 변경 시 선택 후 스크롤 과정이 번거롭다고 보고하고, 클릭 즉시 부드러운 자동 중심 이동을 요구했다. **그 불편 보고와 이번 검색 경로의 자동 이동 관찰을 함께 보존**한다. 개선 목표는 우리 앱의3D/목록/검색 선택 모두에서 동일한 자동 포커스를 제공하는 것이다. 해당 사이트에 자동 이동이 전혀 없다는 결론은 내리지 않는다.

## 첫 화면과 조작

- 주 화면은 천체/관측에 집중하고 상세 정보는 필요할 때 여는 경험을 참고한다. 좌우 패널 배치 자체를 고정 규칙으로 삼지 않는다. 자동 포커스·사용자 제어/중단·상태 보존·UX01–06은 FSD2.1–2.4절이 최신 명세다.
- 검색으로 천체/좌표를 선택하면 object_id와 예상 방향/epoch를 공유해 관측 목록을 조회한다. 노출을 고르면 observation_id·release·시각/파장·WCS·원본 링크·품질과 연결한다.
- 사용자가 날짜·파장을 선택하되 실제 있는 노출만 목록/범위로 제시한다. 관측 없음·다운로드 중·품질 제외·미검증은 각각 표시한다. 자유카메라/모형시간을 바꿔도 실사진의 촬영 위치/시각은 그대로다.
- 영상 비교/깜빡임과 그래프 점 선택은 같은 관측 ID를 공유한다. 상세 정보를 연 상태에서도 천체 선택/주요 화면을 잃지 않게 한다.
- 안내는 3D→명왕성→실노출→개별 가설→별도 위치분포→근거 저장/복원으로 이어진다. 이 경로를 생략하고 좌표/관측 비교부터 시작하는 진입도 유지한다.

## Planet X 실험과 위치 분포

- 개별 가상 행성/궤도 경로와 문헌 표본의 넓은 조건부 위치 분포를 별도 레이어로 제공한다. 문헌/epoch/필터/정규화·면적단위를 표시한다.
- 팀원 제안의 빨강=높음/파랑=낮음 표현을 사용할 때 색상 범례·수치/단위·색상 외 설명을 함께 제공한다. 색이 행성의 존재확률을 뜻하는 것으로 설명하지 않는다.
- 영역 클릭의 백분율은 해당 영역에 들어가는 문헌 표본 비율을 명시한 조건 아래 계산할 수 있을 때만 제공한다. 면적당 밀도와 영역 확률을 분리한다. 전파/epoch 검증 전2018 표본을2026 위치 지도로 표시하지 않는다.
- 가상 행성의 질량/주기/기울기/위치 제안은 기존 가설 경로 실험 범위 안에서 물리적으로 일관된 입력으로 구현한다. 주기와 반장축·중심질량을 Kepler 관계로 묶고 개별경로 변경을 문헌분포 재추론으로 보이지 않게 한다.
- 사용자 간 가설 공유는 우선 파일 내보내기/가져오기로 범위 내 재현을 검토한다. 공개 게시판/계정/장기 저장·BGM·독립 거리/크기 도구는 제안 상태이며 자동 필수 기능으로 추가하지 않는다.

상기 항목의 최종 개발 계약은 FSD2/9절에 통합한다. 특화 경로는 실제SPHEREx노출→개별가설투영→별도문헌분포→원본/설정/결과·판단 저장/새세션복원으로 정의하며, 다른 서비스 기능의 부재/우월성을 검증 없이 주장하지 않는다.

## 공개물 검수

디자인 담당이 제공한 A–D 체크리스트는 **초안 수신**으로 기록한다. 실제 웹·영상/음성/자막·썸네일·크레딧·원자료/AI/코드 출처·라이선스·수치/검증 상태를 앱/최종 산출물에서 다시 확인한다. 만18세 미만 식별정보·계정/알림·개인 경로·NASA 로고를 점검한다. 공식 SI 표시 규칙은 최신 `official_rules.md`를 추가 적용한다.
