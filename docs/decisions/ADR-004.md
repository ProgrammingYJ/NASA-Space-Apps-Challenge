# ADR-004 — 1000 AU 태양계·제9행성 가설과 관측 범위에 집중

> 후속DEV-018에서 숨김만 하는 결정과 역사혜성 유지가 대체됐다. 현재는 해당기능의실제코드/API/새배포 의존성제거·태양계시간재생유지·EC2전환을사용자가승인했다. 현재정본은FSD1.1/2.21/17.4절이며아래는DEV-017결정이력이다.

상태: **채택** · 2026-11-15 KST · 작업 `DEV-017`.

사용자가 전달한 팀 회의 결정과 후속 적용 지시를 따른다. 태양계 탐색·행성 3요건·실제 SPHEREx 관측·근거 복원을 유지하고, 제9행성 가설의 위치 예측과 실제 촬영 범위를 연결한다. 사용자가 추가 요청한 중력은 검증 가능한 제한 모형으로 제공한다. 이 문서는 결정 이유와 경계만 기록하며, 최신 기능·화면·API·저장·검사 계약은 [FSD.md](../../FSD.md), 데이터 전수 목록은 [Data_Spec.md](../../Data_Spec.md)가 정본이다.

## 선택과 이유

1. **은하·은하지도·외계행성 도감·빅뱅/우주 역사·블랙홀·독립 물리실험실의 공개 진입을 비활성화한다.** 원본·manifest·해시·이전 코드와 근거는 보존한다. 단순 파일 삭제는 이전 근거의 무결성 검사와 재현을 깨뜨릴 수 있다. 초기화·저장 상태 복원·조회 실행·직접 API 진입에도 같은 제한을 적용한다. 내부의 이전 근거 검증을 공개 화면 재개방과 구분한다.
2. **기존 Node.js 단독 실행을 유지한다.** 진입점은 루트 `app.js`, 명령은 `node app.js`다. 기존 FITS 처리의 검증된 빌드 캐시를 보존하며 새 런타임 FITS 분석·정밀 운동 측정을 구현했다고 주장하지 않는다. ε Indi B는 공식 대상 검증 사례로 유지한다. 현재 검증 범위는 실제 원본·예측 위치 투영·품질·저장/복원이며 독립 측정된 이동의 증명은 아니다.
3. **제9행성의 단일 가설 경로와 제한된 중력 계산을 분리한다.** 하늘 경로는 태양 점질량의 질량 없는 시험입자 Kepler 모형이다. 별도 중력 계산에는 태양과 처방된 8개 대표 행성계의 뉴턴 중력, 태양 중심 좌표계의 간접항, 선택한 가설의 별도 중력원, 선택적인 태양 1PN 항을 제공한다. 행성 위치는 JPL 적합요소에서 얻으며 상호 중력으로 다시 적분하지 않는다. 가설 질량은 다른 위치/시험입자에 작용하는 중력원으로 사용할 수 있지만 자기 자신의 시험입자 궤도에 되먹임하지 않는다.
4. **MOST 결과는 촬영 범위 근거로 저장한다.** 관측 영상의 검출·천체 연관·실측 운동·발견으로 승격하지 않는다. 정상 조회 0개, 서비스 실패, 이전 응답 재사용을 구별한다. 요청은 고정 IRSA 주소·허용 파라미터·기간/응답 크기/동시성 제한과 정상 TLS 검증을 사용한다. MOST의 SPHEREx 관측자 기준이 독립 확인됐다고 단정하지 않는다.
5. **새 가설 근거 형식을 기존 관측 근거와 별도로 둔다.** 궤도·좌표/시간/관측자 가정·계산 버전·출처 해시·조회 조건·원 응답과 해시·판단을 보존한다. 해시만 남겨 응답 내용을 잃지 않는다. 예측·중력은 현재 모형으로 재계산해 대조하고, 버전/자료가 달라지면 재계산 필요를 표시한다. 가져온 파일의 SHA는 내용 무결성 검사이며 외부 자료의 진위 인증이 아니다. 기존 관측 근거 형식과 검증은 유지한다.

## 과학·수치 경계

- **1000 AU는 태양 중심의 연구 영역 표시다.** 힘이나 궤도를 자르는 물리적 벽이 아니다. 알려지지 않은 천체를 자동 생성하거나 영역 내 모든 물질을 확보했다고 주장하지 않는다.
- Caltech 원본의 `varpi`는 근일점 경도이므로 `ω=(ϖ−Ω) mod 360`으로 변환한다. 원 숫자 epoch `JD 2458270.0`을 보존한다. 이는 달력상 2018-05-31 정오이지만 원문은 “1 June 2018”이라고 적혀 있다. 원 시간계는 미확인이며 TDB는 이 실험의 명시적 가정이다. 반올림된 원소와 미확인 관측자 조건에서 저자 RA/Dec를 정확히 재현했다고 주장하지 않는다.
- 위치는 태양 중심 평균 J2000 황도 AU, 속도는 AU/TDB-day, 가속도는 AU/day²와 m/s²로 구분한다. 하늘 표시는 IAU1976 경사각의 평균 J2000 적도 회전과 반복 광행시간을 사용한다. 관측자는 선택한 태양 또는 JPL 근사의 지구–달 질량중심이며 지구 중심·SPHEREx·자유 카메라와 동일시하지 않는다. 정밀 ICRS 실현, 광행시간 동안 태양의 질량중심 운동, 광행차·빛 휨은 미포함이다.
- P9 관측자·힘 계산의 행성 위치는 1800–2050년에 JPL short 적합표, 나머지 지원 범위에 long 표를 사용하며 사용 표를 결과에 기록한다. 표 경계의 연속성이나 명목오차를 전 구간 정확도 보장으로 해석하지 않는다. 기존 탐색 화면의 장기 모형 계약은 별개다.
- GM은 JPL DE440 표를 사용한다. 지구와 달의 GM을 EMB 위치에 합치며 다른 대표 행성계도 개별 위성을 분해한 힘 계산이 아니다. 태양 1PN은 ASSIST 논문 식 (1)의 약한 장·중심 질량 시험입자 근사만 독립 구현한다. ASSIST 전체 코드나 천체력 수준 정확도를 채택한 것이 아니다.
- 적분은 비동기 RK4와 시간 간격 절반 비교를 사용한다. 근일점 ≥35 AU, 절대 기간 ≤14,610일, 요청 간격 0.05–4일, 큰 간격 기준 최대 4,096단계로 제한하고 유한값·가까운 점질량 접근·실행 시간·취소를 검사한다. 수치 간격 비교는 물리적 불확도나 보장 오차 상한이 아니다. 행성 섭동/1PN에서 태양 2체 비에너지 변화는 전체 에너지 보존 오차가 아니다.
- 전체 상호 N체, 궤도 피팅/공분산·장기 안정성, 개별 위성·고리 중력, J2·고차 다중극·조석, 복사압·태양풍·혜성 비중력, 은하 조석·통과별, 완전 상대론·양자·전자기·유체 계산은 이번 구현에서 제외한다. 행성 3요건의 공식 분류와 조건부 궤도 청소 판별식도 분리한다.

## 확인 근거와 후속 조치

`node/planet-nine.test.js`·`node/solar-gravity.test.js`의 실제 13개 검사를 통과했다. 원/타원 궤도·vis-viva·역제곱·SI 변환·간접항·가설 질량 배율·1PN 한계·RK4/보존량·취소/입력 경계를 확인했다. 보존된 명왕성 4시각의 ELEMENTS에서 별도 VECTORS 위치를 재구성한 최대 잔차는 약 `5.43×10⁻¹³ AU`다. 이는 같은 JPL 모형의 좌표 일관성 검사이며 독립적인 물리 정확도나 실측 운동 검증이 아니다. 로컬 수치 보고서는 `var/qa/dev017-science-review.json`에 모듈 해시와 함께 남겼다.

별도 실제 MOST 검사는 명왕성 이름/NAIF 조회와 수동 요소 조회 각각 20행 및 알려진 D3 노출 3개를 확인했다(`var/qa/dev017-most-live/report.json`). 이 확인은 노출 범위 조회에 한정한다. 브라우저·새 세션·서버 재시작·완결 ZIP·공개 서비스의 실제 완료 여부는 FSD와 작업 기록에서 각각 확정한다. HiPS와 추가 카탈로그는 핵심 경로를 막지 않는 선택 작업이며, 광범위한 동역학과 물리적 자료 삭제/이관은 후속 결정으로 남긴다.
