# ADR-002 · 우주 탐색을 기본 화면과 세션 맥락으로 유지

구현 · DEV-002 · 2026-11-14 KST. 사용자가 DEV-001의 독립 관측 화면이 원하는 제품 흐름과 다르다고 정정했다. FSD2.1의 기본 우주 화면 계약을 실제 진입점에 적용한다. 관측·저장 기능은 그대로 재사용하며 새 별도 앱을 만들지 않는다.

하나의 Three.js scene을 유지하고 탐색·대상정보·관측/근거 패널을 그 위에 연다. 클릭/목록/검색은 같은 object_id와 자동 카메라 포커스를 사용한다. 패널을 닫을 때 scene을 다시 만들지 않는다. 각 object_id의 관측/판단은 별도 workspace에 보관해 다른 천체로 옮겨도 섞이거나 사라지지 않게 한다. 이전 component가 unmount된 뒤 돌아오는 비동기 응답은 무효화한다.

태양계 위치는 보존한 JPL Horizons의 실제4시각만 사용한다. ε Indi B는 별도의 방향층이다. 화면거리압축과 천체크기확대/외관/별배경은 표현 가정으로 알린다. 카메라는 실제 SPHEREx 관측자가 아니며 모형 시각과 실제 노출 시각은 분리한다. 실제 Pluto 노출의 표식은 SPHEREx 관측자 전용 Horizons 예측을 사용한다.

기존 근거schema1.0에 optional universe_context를 추가한다. context가 존재하면 해당 장면 출처 SHA·모형시각·선택대상·표현버전과 유효한 카메라를 함께 확인한다. 이전context없는 근거도 복원한다. 전체데이터/계산·API필드·UI수용기준의 최신명세는 FSD가 정본이며 여기서는 변경이유/경계만 기록한다.

독립 전체페이지로 관측으로 이동하는 방식은 공간맥락을 잃으므로 선택하지 않았다. 항상모든분석패널을펼치는 방식도 초기탐색을가리므로 선택하지 않았다. 기본은우주전체화면, 천체선택시정보, 실제관측은선택한맥락에서열고닫는다. 되돌리기는별도이전릴리스로실행하며원본/근거volume은초기화하지않는다.
